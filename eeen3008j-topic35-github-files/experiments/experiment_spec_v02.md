## 模型与事件顺序

沿用 v0.1 第 2—7 节数学定义与收费口径，以下重述正式参数和变化，冲突以本文件及协调决定为准。

单对象、一维位置 p/m、瞬时速度 v/(m/s)，发送端无噪声准确观测，共享时钟。T=60 s、Δt=0.01 s，取 [0,T) 的事件后网格值。两端 t=0 精确共享 p=0,v=1，初始化开销不计入增量通信，披露有限时长效应。

随机运动为解析分段恒速：`p(t)=t+Σ Δv_i max(0,t−τ_i)`，`v(t)=1+Σ Δv_i 1[t≥τ_i]`。从 start=2,4,…,58 s，每个区间在 start+U(0.1,1.8) s 发生一次机动，四舍五入至网格，Δv_i 为等概率 ±|Δv|。负速度表示反向；跳变是抽象失配场景，不是有界加速度车辆模型。

接收端对最新采用样本 `(s_r,p_r,v_r)` 使用 `p_hat_r(t)=p_r+v_r(t−s_r)`。到达时推进到当前时刻；仅接受生成时间严格更新的包。接收端 AoI=`t−s_r`，成功接收时一般降至数据交付时延，不降零。实际评价误差 `e_eval=|p−p_hat_r|`。

数据逻辑包32 B：时间戳8+位置8+速度8+序号4+头4；ACK16 B：时间戳8+序号4+头4。不做二进制编码/量化，不代表完整空口字节。速率3200 bit/s，数据/ACK服务时长分别0.08/0.04 s；默认额外前向/ACK时延0.05/0.02 s，主扫描无抖动。所有数值均 illustrative，非实测或文献规定。

停等、无队列，一次只允许一个事务。忙时周期机会跳过；失败不重传旧包，超时后若满足策略就采样当前状态。超时为数据服务+额外前向最大时延+ACK服务+ACK时延+一个时隙，各项时延向上取整至网格。ACK可靠且必早于超时；失败没有ACK。数据/ACK成功与否仅通过网络内部事件处理；发送端不读取未来信道或接收端状态。

同一时隙先处理旧数据到达/丢失、ACK/超时，再作发送判断，若空闲触发则生成并发送，最后记录事件后指标；理想零服务检查允许同一时隙即时送达。截止不排空网络，保存数据和ACK在途计数。生成的发送数据立即全额收费，ACK在接收端生成时全额收费，包括跨终点的预留序列化；reserved_service_s 不等于观测窗内实际 airtime。

## 发送端信息、四策略与协议边界

发送端根据已收到ACK的样本建立副本 `(s_a,p_a,v_a)`，ACK引用本地缓存。`p_hat_s=p_a+v_a(t−s_a)`，触发误差=`|p−p_hat_s|`，发送端年龄=`t−s_a`。和评价误差分开。

| 标记/实现名 | 允许发送且k>0时的条件 | 工作点 |
|---|---|---|
| P / periodic | 绝对网格 k 为 P/Δt 的正整数倍 | P=0.25/0.5/1/2/4 s |
| A / age | 发送端年龄≥A | A同上 |
| E / error | 触发误差>η | η=0.05/0.1/0.2/0.5/1 m |
| EA / error_age | 触发误差>η 或 发送端年龄≥A | 5×5组合 |

比较浮点容差1e−12，误差严格超阈值、年龄含等号。误差阈值与评价容限 ε=0.5 m 不同。每条件40点。

**修正 v0.1 的解释**：ACK等待期间两副本可能不同，但可靠停等使下一次允许发送时两端已一致。实现对所有空闲决策时隙断言整个样本一致，并累计 eligible_decisions；不把此断言作为控制器输入。ACK延迟切片验证的是事务占用和发送机会受限，不能证明决策时持过时副本的鲁棒性。ACK丢失不在模型内，不能外推。

当无损且事务在下一次阈值前结束、P=A时，周期/年龄可能完全重合；长ACK或忙时跳过可改变此条件。E在恒速准确初始化时合法地零发包、零误差；不得删掉零开销点，也不预设EA优于E。

## 外生随机过程、指标与统计

同 seed 同条件的全部策略/工作点复用同一轨迹和按发送时隙索引的信道。运动/丢包/时延 RNG 独立分流：seed+1000003、seed、seed+2000003。信道不是按发包序号抽样。

逐运行计算位置 RMSE、超容限时间/比例、平均/最大AoI、数据/ACK/总字节及总字节率；与v0.1公式相同。守恒 `attempts=lost+delivered+data_inflight`、`delivered=accepted+stale`、`ack_generated=ack_delivered+ack_inflight`；失败尝试也计费。主指标为位置精度，AoI不能替代。

主扫描 |Δv|={0,0.5,1,2} m/s × loss={0,0.1,0.3}。调参 seeds=0…9（4800运行），评估 seeds=100…129（14400运行），固定n=30，无依显著性扩充停止规则。14400运行不是14400独立轨迹；同seed跨参数共享轨迹。

每工作点每指标给运行级均值及95% percentile bootstrap CI，10000次重采样，固定统计seed=20261103。所有工作点使用相同的30个seed重采样索引，保留策略配对；策略差异对同seed差值作CI。不是时间点重采样，不是同时置信带；n=30、未做多重比较调整，区间可能不稳定。

在每个运动×损失条件、每类策略的调参均值上，对预算24/48/96 B/s，筛选字节率不超预算的候选，再按RMSE、字节率、point_id依次破平；无可行点写null。先保存选择文件再读取评估数据；配置冻结后报告评估实际字节率和超预算运行数。不是硬预算/严格等消耗比较。不从评估集择优后声称最优优势；评估全部工作点及经验前沿仅描述性展示。
